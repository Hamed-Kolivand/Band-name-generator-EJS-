📖 درباره پروژه
این پروژه یکی از تمرین‌های دوره‌ی فول‌استک وب آنجلا یو است و هدف آن تمرین موارد زیر است:

ساخت وب‌سرور با Node.js و Express.js

مدیریت ارسال فرم‌ها با متد POST و body-parser

رندر صفحات HTML داینامیک با EJS

پردازش ورودی کاربر و نمایش نتیجه

برنامه از کاربر می‌خواهد نام خیابان و نام حیوان خانگی خود را وارد کند، سپس آن‌ها را ترکیب کرده و یک نام بند جذاب تولید می‌کند.

 تکنولوژی‌های استفاده‌شده
Node.js

Express.js

EJS

Body-parser

HTML, CSS


روش اجرا در VS Code
برای اجرای این پروژه روی سیستم خودتان، مراحل زیر را به ترتیب انجام دهید:

۱. کلون کردن پروژه

bash
git clone https://github.com/Hamed-Kolivand/Band-name-generator-EJS-.git
cd Band-name-generator-EJS-
۲. نصب وابستگی‌ها

bash
npm install
۳. اجرای سرور

bash
node server.js
یا اگر nodemon دارید:

bash
nodemon server.js
۴. باز کردن در مرورگر

text
http://localhost:3000
۵. استفاده از برنامه

نام خیابان و نام حیوان خانگی خود را وارد کنید

روی دکمه‌ی Submit کلیک کنید

نام بند تولیدشده را ببینید!
